# Baito - support site

The support and privacy pages for the Baito iOS app, served via GitHub Pages
at https://jeremydevdesign.github.io/baito-support/.

- `index.html` - support page and FAQ
- `privacy.html` - privacy policy
- `style.css` - shared styles
- `icon.png` - app icon

This repository contains only these static pages. The app itself is closed
source and lives elsewhere; the source copy of these pages is its `store/site`.
